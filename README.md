# Act+Acre Product Page

A responsive product page for Act+Acre, built with vanilla JavaScript and Parcel.

## Getting Started

### Prerequisites

- Node.js v18+
- npm v9+

### Installation

```bash
npm install
```

### Development

```bash
npm start
```

### Build

```bash
npm run build
```
